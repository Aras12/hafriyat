═══════════════════════════════════════════════════════════════════════════════
ADIM 1: DOSYALARI YÜKLE
═══════════════════════════════════════════════════════════════════════════════

ZIP'i aç, TÜM dosyaları sunucuya yükle:
- cPanel → Dosya Yöneticisi
- public_html/ (veya addon domain klasörü)
- Upload → ZIP seç → Extract (Çıkart)

═══════════════════════════════════════════════════════════════════════════════
ADIM 2: VERİTABANI OLUŞTUR
═══════════════════════════════════════════════════════════════════════════════

cPanel → MySQL Databases:

1. Yeni veritabanı: emirhafriyat
2. Yeni kullanıcı: emiruser + şifre
3. Kullanıcıyı DB'ye ekle + ALL PRIVILEGES
4. phpMyAdmin → database.sql import et

═══════════════════════════════════════════════════════════════════════════════
ADIM 3: config.php DÜZENLE
═══════════════════════════════════════════════════════════════════════════════

Sadece 4 satırı değiştir:

define('DB_NAME', 'kullaniciadi_emirhafriyat');  ← DB tam adı
define('DB_USER', 'kullaniciadi_emiruser');      ← Kullanıcı tam adı
define('DB_PASS', 'sifreniz');                   ← Şifre
define('SITE_URL', 'https://adanaotokokusu.com.tr'); ← Domain
