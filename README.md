# KAYSERİ EMİR HAFRİYAT - Website

Modern ve profesyonel hafriyat firması web sitesi.

## 🎯 Özellikler

- ✅ Tamamen HTML + CSS + Bootstrap 5 + JavaScript
- ✅ Framework yok (React, Vue, Next, PHP kullanılmamıştır)
- ✅ Mobil uyumlu (Responsive)
- ✅ SEO optimize edilmiş
- ✅ Lazy loading resim desteği
- ✅ WhatsApp entegrasyonu
- ✅ Hızlı iletişim butonları
- ✅ Modern ve şık tasarım

## 📁 Dosya Yapısı

```
/
├── index.html              # Ana sayfa
├── hakkimizda.html        # Hakkımızda sayfası
├── hizmetler.html         # Hizmetler sayfası
├── galeri.html            # Galeri sayfası
├── projeler.html          # Projeler sayfası
├── iletisim.html          # İletişim sayfası
│
└── assets/
    ├── css/
    │   └── style.css      # Ana CSS dosyası
    ├── js/
    │   └── main.js        # JavaScript dosyası
    └── img/
        ├── slider/        # Slider resimleri
        ├── galeri/        # Galeri resimleri
        ├── hizmetler/     # Hizmet resimleri
        └── projeler/      # Proje resimleri
```

## 🚀 Kurulum ve Kullanım

1. ZIP dosyasını çıkartın
2. Resimlerinizi ilgili klasörlere yerleştirin:
   - `assets/img/slider/` (slider1.jpg, slider2.jpg, slider3.jpg)
   - `assets/img/galeri/` (galeri1.jpg - galeri18.jpg)
   - `assets/img/hizmetler/` (ekskavator.jpg, bekoloder.jpg, vb.)
   - `assets/img/projeler/` (proje1.jpg - proje6.jpg)
3. `index.html` dosyasını tarayıcıda açın
