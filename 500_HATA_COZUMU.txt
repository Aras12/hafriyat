===============================================================================
HTTP 500 HATASI ÇÖZÜMÜ - ADIM ADIM
===============================================================================

SORUN: https://demosu.gen.tr/hafriyat açılmıyor, HTTP 500 hatası

ÇÖZÜM: 3 Basit adımda halledelim!

===============================================================================
ADIM 1: .htaccess'i Geçici Kaldır
===============================================================================

Sunucunuzda (cPanel → Dosya Yöneticisi):

1. /hafriyat/ klasörüne gidin
2. .htaccess dosyasını bulun
3. Sağ tık → Yeniden Adlandır
4. Yeni ad: .htaccess.KAPALI
5. Kaydet

Şimdi test edin:
   https://demosu.gen.tr/hafriyat/index.php

✅ AÇILDI MI? → Sorun .htaccess ile! ADIM 2'ye geç
❌ Hala 500? → Sorun PHP ile! ADIM 3'e geç

===============================================================================
ADIM 2: Basit Test (PHP Çalışıyor mu?)
===============================================================================

Sunucuda yeni dosya oluşturun:
   Dosya adı: basit-test.php
   İçerik:

<?php
echo "✅ PHP ÇALIŞIYOR!<br>";
echo "PHP: " . phpversion() . "<br>";
?>

Kaydedin ve açın:
   https://demosu.gen.tr/hafriyat/basit-test.php

✅ "PHP ÇALIŞIYOR" görüyorsanız → PHP çalışıyor, config.php'de hata var
❌ Hala 500 → Sunucu PHP sorunu, hosting desteğe başvurun

===============================================================================
ADIM 3: config.php Kontrol
===============================================================================

Sunucuda /hafriyat/config.php dosyasını açın

KONTROL 1: Veritabanı bilgileri doğru mu?
   define('DB_NAME', 'emirhafriyat_db');  ← Veritabanı adınız doğru mu?
   define('DB_USER', 'root');              ← Kullanıcı adınız doğru mu?
   define('DB_PASS', '');                  ← Şifreniz doğru mu?

KONTROL 2: Syntax hatası var mı?
   - Tüm satırlar ; ile bitiyor mu?
   - Tırnak işaretleri kapalı mı?
   - <?php ile başlıyor mu?

===============================================================================
ÇÖZÜM A: .htaccess OLMADAN ÇALIŞTIR
===============================================================================

Eğer index.php (doğrudan) çalışıyorsa:

1. .htaccess'i kaldırın (ADIM 1)
2. Siteyi şöyle kullanın:
   - Ana sayfa: /hafriyat/index.php
   - Hakkımızda: /hafriyat/hakkimizda.php
   - Blog: /hafriyat/blog.php
   - Admin: /hafriyat/admin/login.php

3. URL'lerde .php uzantısı olacak (sorun değil!)

4. Çalıştıktan sonra .htaccess'i yavaş yavaş ekleriz

===============================================================================
ÇÖZÜM B: MİNİMAL .htaccess KULLAN
===============================================================================

Eğer .htaccess olmadan çalışıyorsa:

1. Sunucuda .htaccess dosyası oluşturun
2. İçine SADECE şunu yazın:

Options -Indexes

3. Kaydet ve test et
4. Çalışıyorsa yavaşça kurallar ekleriz

===============================================================================
HIZLI TEST LİSTESİ
===============================================================================

1. ✅ basit-test.php çalışıyor mu?
   Evet → PHP tamam
   Hayır → Sunucu sorunu

2. ✅ index.php (doğrudan) çalışıyor mu?
   Evet → .htaccess sorunu
   Hayır → config.php sorunu

3. ✅ Veritabanı oluşturdunuz mu?
   Evet → Devam
   Hayır → database.sql import edin

4. ✅ DB bilgileri config.php'de doğru mu?
   Evet → Devam
   Hayır → Düzeltin

===============================================================================
BENİ ARAYIN - NE SÖYLEMEM LAZIM?
===============================================================================

Bana şunları söyleyin:

1. basit-test.php açıldı mı? ✅ veya ❌
2. index.php açıldı mı? ✅ veya ❌
3. .htaccess'i kaldırınca açıldı mı? ✅ veya ❌
4. Hangi hata mesajını görüyorsunuz? (varsa)
