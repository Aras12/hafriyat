═══════════════════════════════════════════════════════════════════════════════
  1. SİSTEM GEREKSİNİMLERİ
═══════════════════════════════════════════════════════════════════════════════

✓ PHP 7.4 veya üzeri
✓ MySQL 5.7 veya üzeri (MariaDB 10.2+ desteklenir)
✓ Apache Web Server (mod_rewrite etkin)
✓ PDO PHP Extension
✓ GD veya Imagick Extension (resim yükleme için)
✓ Minimum 50 MB disk alanı

═══════════════════════════════════════════════════════════════════════════════
  2. DOSYALARI YÜKLEME
═══════════════════════════════════════════════════════════════════════════════

1. ZIP dosyasını çıkartın
2. Tüm dosyaları FTP ile sunucunuza yükleyin
   - Ana dizine yükleyebilir (public_html/)
   - Alt klasöre yükleyebilirsiniz (public_html/emirhafriyat/)

3. Dosya izinleri:
   chmod 755 /assets/img/
   chmod 755 /admin/uploads/
   chmod 644 config.php

═══════════════════════════════════════════════════════════════════════════════
  3. VERİTABANI KURULUMU
═══════════════════════════════════════════════════════════════════════════════

1. cPanel veya phpMyAdmin'e giriş yapın
2. Yeni bir veritabanı oluşturun (örn: emirhafriyat_db)
3. Veritabanı kullanıcısı oluşturun ve şifre belirleyin
4. Kullanıcıya veritabanı üzerinde TÜM yetkiler verin
5. "database.sql" dosyasını içe aktarın (Import)

   MySQL komut satırı ile:
   mysql -u kullanici_adi -p veritabani_adi < database.sql

═══════════════════════════════════════════════════════════════════════════════
  4. CONFIG.PHP AYARLARI
═══════════════════════════════════════════════════════════════════════════════

config.php dosyasını düzenleyin:

// Veritabanı ayarları
define('DB_HOST', 'localhost');           // Genellikle 'localhost'
define('DB_NAME', 'emirhafriyat_db');     // Veritabanı adınız
define('DB_USER', 'veritabani_kullanici');// Veritabanı kullanıcı adı
define('DB_PASS', 'veritabani_sifresi');  // Veritabanı şifresi
define('DB_CHARSET', 'utf8mb4');

// Site URL'i (otomatik tespit eder, değiştirmeye gerek yok)
define('SITE_URL', rtrim(dirname($_SERVER['SCRIPT_NAME']), '/'));

ÖNEMLI: Production ortamında hata gösterimini kapatın:
error_reporting(0);
ini_set('display_errors', 0);

═══════════════════════════════════════════════════════════════════════════════
  5. .HTACCESS KONTROLÜ
═══════════════════════════════════════════════════════════════════════════════

- .htaccess dosyasının sunucuya yüklendiğinden emin olun
- Apache mod_rewrite modülünün aktif olduğunu kontrol edin
- Eğer alt klasöre kurduysan iz, RewriteBase'i düzenleyin:
  RewriteBase /altklasör/

4. BLOG
   ✓ Örnek blog yazılarını inceleyin
   ✓ Kendi içeriklerinizi ekleyin

═══════════════════════════════════════════════════════════════════════════════
  9. SMTP MAİL AYARLARI (İSTEĞE BAĞLI)
═══════════════════════════════════════════════════════════════════════════════

İletişim formundan gelen mesajların e-posta olarak gönderilmesi için:

Admin Panel → Ayarlar → SMTP Ayarları

Gmail için örnek:
  SMTP Host: smtp.gmail.com
  SMTP Port: 587
  Şifreleme: TLS
  Kullanıcı Adı: sizinemail@gmail.com
  Şifre: uygulama_sifresi

Not: Gmail için "Uygulama Şifresi" oluşturmanız gerekebilir.

═══════════════════════════════════════════════════════════════════════════════
  10. SORUN GİDERME
═══════════════════════════════════════════════════════════════════════════════

❌ SORUN: "500 Internal Server Error"
✅ ÇÖZÜM:
   - .htaccess dosyasını kontrol edin
   - PHP hata loglarını inceleyin
   - Dosya izinlerini kontrol edin

❌ SORUN: "Database connection failed"
✅ ÇÖZÜM:
   - config.php veritabanı bilgilerini kontrol edin
   - Veritabanı kullanıcı izinlerini kontrol edin
   - MySQL servisinin çalıştığından emin olun

❌ SORUN: Resimler yüklenmiyor
✅ ÇÖZÜM:
   - /assets/img/ klasörü yazılabilir olmalı (chmod 755)
   - PHP upload_max_filesize ayarını kontrol edin
   - GD veya Imagick extension'ın kurulu olduğunu kontrol edin

❌ SORUN: SEF URL'ler çalışmıyor
✅ ÇÖZÜM:
   - .htaccess dosyasının yüklendiğinden emin olun
   - Apache mod_rewrite modülünün aktif olduğunu kontrol edin
   - AllowOverride All ayarının yapıldığından emin olun

❌ SORUN: Admin panele giriş yapamıyorum
✅ ÇÖZÜM:
   - Kullanıcı adı: admin
   - Şifre: admin123
   - Tarayıcı çerezlerini temizleyin
   - database.sql dosyasının doğru import edildiğini kontrol edin
